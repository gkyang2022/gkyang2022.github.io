前言：告别手动查找，一站式聚合搜索！

哈喽大家好！

往期我们分享了 PanSou，很多朋友都说非常实用。今天，我将为大家带来一个功能更强大的聚合网盘搜索项目！它不仅拥有更丰富的搜索源，还支持两种部署方式：本地 Docker 和 Vercel/Cloudflare 一键部署。

无论你有没有 NAS，都能轻松搭建一个属于你自己的资源搜索引擎，高效、便捷地找到全网资源。

🎬 部署教程：本地 Docker 与 Vercel 两种方式任你选

视频教程

1. 本地 Docker 部署（推荐有 NAS 的用户）

如果你有 NAS，那么本地部署是最好的选择，稳定且无流量限制。

  1. 创建项目文件夹：

    • 登录你的飞牛 NAS，进入文件管理界面。
    • 在合适的目录下（例如 docker 文件夹），新建一个名为 pansou-plus 的文件夹。

  2. 部署 Docker Compose：

    • 打开 Docker，选择 Compose。
    • 点击 “新增项目”，项目名称填写 pansou-plus，项目路径选择我们刚才创建的文件夹。
    • 将下面的 Docker Compose 代码复制并粘贴到编辑框中。
  1. 开始构建：
    • 点击 “确定”，系统会自动下载镜像并开始构建。构建完成后，你就可以在浏览器中通过 你的NAS的IP地址:端口号 来访问它了。

2. Vercel 一键部署（推荐无 NAS 的用户）

如果你没有 NAS，或者不想在本地部署，Vercel 提供了一个零成本、一键式的部署方案。

  1. 访问项目主页：

    • 前往该项目的 GitHub 主页。
    • 找到并点击 “Deploy” 按钮。

  2. 自动部署：

    • 点击按钮后，你会被自动跳转到 Vercel 的部署页面。
    • 在 Vercel 页面，只需点击 “Create”，Vercel 就会开始自动拉取代码并部署。

  3. 获取域名：

    • 部署完成后，Vercel 会提供一个专属的 .vercel.app 域名。
    • 你可以通过这个域名来访问你的资源搜索引擎。

  4. 注意事项：

    • Vercel 的免费账号每月有 100G 的流量限制，请在使用时注意。
    • 类似的，你也可以选择在 Cloudflare 上进行部署。

✨ 项目功能深度解析

这个项目之所以比上期介绍的 PanSou 更强大，主要体现在以下几个方面：

  • 更多搜索源：它聚合了更丰富的网盘和电报群搜索源，让你的搜索结果更全面。
  • 支持并发搜索：在设置中，你可以调整搜索的并发数，最大支持 16 个，这能极大地提高搜索效率。
  • 分类与排序：搜索结果提供了清晰的分类展示，内容也按照日期排序，方便你快速找到最新资源。
