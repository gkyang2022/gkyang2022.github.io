前言：告别反复切换 App 的烦恼

作为直播爱好者，你是否也厌倦了在各个平台 App 之间反复横跳？今天分享的这款 GitHub 开源直播聚合项目，将彻底改变你的观播体验。它不仅支持国内主流四大平台，还具备极佳的跨平台兼容性。

✨ 核心亮点

  • 全平台支持：同时集成 抖音、B站、斗鱼、虎牙 四大直播平台。
  • 全系统兼容：支持 Windows、macOS (Apple Silicon/Intel) 以及 Linux。
  • 原生体验：支持实时弹幕显示和聊天互动，看直播更有氛围。
  • 高清画质：进入直播间默认开启最高清晰度。
  • 便捷管理：支持自定义关注列表，多平台主播统一管理。

🎬 部署与使用

1. 下载安装

前往项目的 GitHub Release 页面，根据您的操作系统下载对应的安装包。

点击前往 GitHub 下载

2. 界面展示

软件界面简洁无广告，左侧为平台分类，右侧展示热门直播间。

3. 使用技巧

  • 搜索与分类：可以直接通过关键词搜索主播。
  • 关注功能：点击直播间的收藏按钮，即可在首页“关注”栏快速找到他们。
  • 弹幕设置：可以在设置中调整弹幕的透明度和显示位置。

总结

这款聚合工具在保持轻量化的同时，完美兼顾了画质与互动，是目前 PC 端看直播的最佳选择之一。如果你也喜欢看直播，赶紧去 GitHub 给作者点一颗星星并下载体验吧！
