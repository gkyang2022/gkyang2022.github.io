MoonTV最新版保姆级部署教程：解决旧版失效问题

NAS玩家们，你们是否发现之前部署的 MoonTV 无法正常使用了？这是因为官方更新了版本，导致旧版容器无法正常运行。直接升级可能会出现未知错误，因此最稳妥的方法是彻底卸载旧版，然后重新部署最新版本。

本教程将手把手指导你完成整个过程，操作非常简单，即使是新手也能轻松掌握。

视频教程

如果你更喜欢通过视频学习，可以观看下面的教程。本篇博文的内容与视频同步，方便你边看边操作。

第一步：彻底卸载旧版MoonTV

在部署新版之前，请务必完成这一步，以避免新旧版本之间的冲突。

  1. 停止并删除容器

    登录你的飞牛NAS，进入 Docker 管理界面。

    • 找到旧的 MoonTV 容器并点击停止。

    • 如果你是按照之前的教程部署的，通常会有一个 Redis 容器，也要一并停止。

    • 停止后，将这两个容器都删除。

  2. 删除Compose文件和镜像

    • 切换到 Compose 界面，找到并删除旧的 MoonTV Compose 文件。

    • 进入 本地镜像 库，删除所有与 MoonTV 和 Redis 相关的镜像。

  3. 清理部署文件夹

    • 进入文件管理，找到之前用于部署 MoonTV 的文件夹。

    • 将该文件夹内的所有内容清空，或者直接删除整个文件夹，然后新建一个同名文件夹。

完成以上步骤后，你的部署环境就已清理干净，可以开始部署新版本了。

第二步：部署最新版MoonTV

现在，我们来获取并部署最新的MoonTV容器。

  1. 获取新版Compose文件

    • 访问 MoonTV 的 GitHub 项目页面（🔗 https://github.com/MoonTechLab/LunaTV），找到最新的 Compose 文件代码。

    • 将该文件的全部内容复制下来。

  2. 创建新容器

    • 回到飞牛NAS的 Docker 管理界面，进入 Compose 选项。

    • 点击 “添加” 新的 Compose 任务。

    • 为新任务命名，例如 moontv-new。

    • 选择你之前清空或新建的文件夹作为部署路径。

    • 将复制的 Compose 文件代码粘贴到文本框中。

    • 重要：在粘贴的代码中，找到 username 和 password 两行，并将其修改为你自己的用户名和密码。

  3. 启动部署

    • 确认信息无误后，点击 “确定”。

    • Docker 将自动拉取最新的镜像并创建容器。这个过程需要一些时间，具体取决于你的网络状况。

第三步：登录与配置MoonTV

部署完成后，你还需要进行一些简单的配置才能正常使用。

  1. 登录管理面板

    • 容器构建完成后，进入 Docker 容器列表，找到新部署的 MoonTV 容器。

    • 点击它，进入主界面后，点击右上角的头像，选择 “管理面板”。

  2. 添加源文件

    • 新版的MoonTV默认是没有任何源的，你需要手动添加。

    • 获取最新的源文件内容（通常在项目页面有提供）。

    • 将源文件内容粘贴到管理面板中的相应文本框里，然后点击 “保存”。

至此，你已成功部署并配置好了最新版的MoonTV！现在，你可以享受最新版本带来的流畅观影体验了。

希望这篇教程对你有所帮助。如果你在操作过程中遇到任何问题，欢迎在评论区留言交流。
