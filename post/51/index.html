1. 前置准备

  • 一台已安装 飞牛（FeiNiu）系统 的 NAS
  • 已启用 Docker 与 Compose 插件
  • 可用的端口（避免和现有服务冲突）

2. 创建文件夹

在飞牛的 文件管理 中，为 IPTV 项目新建一个文件夹，例如 iptv，用来存放配置。

3. 创建 Compose 项目

打开 Docker → Compose，点击 新建项目：

  • 名称：填写 IPTV
  • 路径：选择刚刚创建的 iptv 文件夹
